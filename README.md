# Cortexa

Cortexa is a next-generation platform for selling and showcasing websites — combining a cinematic, high-tech user experience with immersive 3D visuals. Built for speed, style, and impact.

## ✨ Features
- Cinematic 3D hero sections powered by Three.js / React Three Fiber
- Smooth scroll-based animations with GSAP
- Glassmorphism + high-tech UI design system
- Fully responsive with optimized mobile fallbacks
- Built on Next.js + Tailwind CSS

## 🛠 Tech Stack
- **Frontend:** Next.js, React
- **3D/Animation:** Three.js, React Three Fiber, GSAP
- **Styling:** Tailwind CSS
- **Hosting:** Vercel
